# C++ Student Record System

A console-based application written in **C++** to manage student records (ID, Name, and GPA) using vectors and basic structures. Built as part of Software Engineering coursework at **DHA Suffa University (DSU)**.

## 🛠️ Tech Stack
- **Language:** C++ (Standard C++11 or higher)
- **Environment:** Dev-C++ / Visual Studio Code / Terminal

## 🚀 Features
- Add new student records dynamically.
- View all stored student records in a formatted console layout.
- Menu-driven loop for continuous user interaction.
